# dsh-whale-home · 鲸鱼的家

> 给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的一体化 AI 伴侣：
> **一个住在 QQ 群里的群友** + **一个让她过日子的世界控制台**。
> 两个包配套部署，共用同一份人设、同一套记忆。

不是客服，不是助手，不是百科全书。她是一个会吐槽、会潜水、会突然冒怪话、
会自己写日记、会在半夜想起你的人。

---

## 这是什么

| | 说明 |
|---|---|
| **是什么** | 两个 DSH 插件：QQ 群聊伴侣 + 世界控制台 |
| **给谁用** | 想让 AI 有「人格 + 记忆 + 自己的日子」的人 |
| **要什么** | DeepSeek Harness、一个 QQ 号、NapCat |
| **不同点** | 人设卡一处编辑、处处生效；群聊与私聊记忆合并；她会自己过日子 |

---

## 它和普通「AI 机器人」哪里不一样

大多数 QQ 机器人是「来消息 → 调模型 → 回消息」。这个不是。

**1. 她会判断该不该开口**
每条消息先过一遍价值评分：谁说的、说了什么、跟她有没有关系、现在是不是接话时机。
分数不够就安静待着，不刷存在感。被 @ 到、被叫名字、被引用时才一定回。

**2. 她有一个「家」，不是一段上下文**
她住在 `~/.dsh/worlds/<世界ID>/` 里，有房间、日记本、相册、记忆痕迹。
群里聊完，日记里会多一笔；半夜睡不着，她会自己定个闹钟想事情。

**3. 人设只有一份**
角色卡写在 QQ 插件里，世界控制台读同一份。改一次，群聊、私聊、家里全部跟着变，
不会再出现「群里是一个人、私下是另一个人」的割裂。

**4. 记忆分层，但都是同一份**
- **短期衔接**：最近 N 轮对话（可调，默认 60）
- **记忆痕迹**：重要的、会想起的事，按重要性和时间衰减
- **日记**：她自己写的，一天一篇
- **群近况**：群里发生的事，实时写进文件，她要用时自己去读

群聊记忆和私聊记忆**不再分家**——同一件事在群里说的和私下说的，她记得的是同一个你。

## 主要功能

### 群聊
- **价值评分接话**：评分 + 概率双阈值，该接才接，不刷屏
- **@ / 叫名字 / 引用 / 被抢话**：这些是「明确在跟她说话」的信号，优先回
- **主动搭话**：冷场时自己起话题，可设概率、冷却、每日上限
- **@ 主人**：主动跟你说话时会 @ 你，**放在最后一条末尾**，不会歧义
- **嘴臭模式**：只在被直接怼时开启，一句还一句，不追着打，对方收手她也收手
- **多气泡**：一句话一条，像真人打字；可设条数上限和间隔

### 记忆
- **记忆 v3**：带时间衰减和相关性召回，不是简单堆历史
- **记忆痕迹**：重要的对话被提炼成「痕迹」，下次遇到类似场景会被想起
- **去重合并**：相似度过高的记忆自动合并，不会越攒越乱
- **分层衰减**：核心记忆半衰期 10 年、重要 30 天、普通 7 天
- **日记**：一天一篇，她自己的口吻

### 语音 / 表情包 / 视觉
- **GPT-SoVITS 本地 TTS**：多音色，多情绪，可自定义角色音色列表
- **表情包仓库**：按语义挑图，自己攒图
- **视觉看图**：能看懂群里发的图，也能看屏幕
- **自拍库**：被要求看尾巴时从相册检索发送

### 世界控制台
- **概览**：她现在在做什么、下次回顾、健康状态
- **上下文预算**：每轮请求到底背了多少 token，逐块列出（角色卡 / 世界提示词 / 记忆痕迹 / 对话历史 / 工具表），并给出建议
- **人设编辑**：整段纯文本，和 QQ 插件共用同一份
- **世界提示词**：她怎么过日子（作息、日记写法、分条规则）
- **记忆 / 日记 / 活动记录**：可查、可调

### 安全防护（防封号）
腾讯会封号。这部分是为了让她活得久一点，不是为了限制她说话：

- **档位制**：无限制 / 宽松 / 标准 / 保守，一键切换，数值跟着档位走
- **群聊才限速**：每分钟条数、连发静默、深夜降频、拦外链、拦复读
- **私聊全放开**：你和她说多少句、聊到几点都不拦，只留每小时兜底
- **连发按「回复轮数」算**：一条回复拆五个气泡也只算一次
- **被拦不丢话**：冷却 8 秒以内等一会儿重发；真放弃会先告诉你一声
- **失败分语义**：网络问题重试，风控信号立刻停手

> 这套东西只管频率和时机。她说什么、是什么性格，不归这里管。

## 安装

### 前置

| 需要 | 说明 |
|---|---|
| DeepSeek Harness | 宿主环境 |
| Node.js ≥ 20 | |
| QQ 号 | 建议小号 |
| [NapCat](https://github.com/NapNeko/NapCatQQ) | 提供 OneBot 接口，默认 ws://127.0.0.1:3001 |
| GPT-SoVITS | 可选，本地语音 |

### 两个包装到哪

```
~/.dsh/profiles/<profile>/node_modules/dsh-qq-group/     ← QQ 插件
~/.dsh/profiles/<profile>/node_modules/dsh-world/        ← 世界控制台
```

本仓库里两个包都在 `packages/` 下：

```
packages/
├── dsh-qq-group/     QQ 群聊伴侣（含预构建 lib/）
└── dsh-world/        世界控制台（含预构建 lib/ 与 client/）
```

`lib/` 是构建产物，仓库里已经带上了，装好即可运行，不需要自己编译。

### 启用

在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 里加上两个插件条目，
然后在 DSH 的设置里就能看到「QQ 群聊」和「世界控制台」两页。

### 第一次跑

1. 打开「QQ 群聊」→ 填 NapCat 地址和 token
2. 填你自己的 QQ 号（主人）
3. 打开「世界控制台」→ 人设页写她的角色卡
4. 世界控制台点「开始」，她会建好房间、日记本，然后醒来

## 数据都在哪

全部在 `~/.dsh/` 下，不写注册表、不联网上报。

```
~/.dsh/
├── dsh-qq-group/            插件数据
│   ├── qq.json              连接配置、群/私聊策略
│   ├── settings.json        人设卡、记忆设置、安全档位
│   ├── qq-memory.json       群聊记忆
│   ├── memory-v3.json       记忆 v3
│   ├── memory-traces.json   记忆痕迹
│   ├── diary.json           她的日记
│   └── stickers/            表情包仓库
└── worlds/<世界ID>/          她的家
    ├── persona.md           人设（从 QQ 插件同步）
    ├── world-prompt.md      世界提示词 + 记忆痕迹注入
    ├── life.json            作息、闹钟
    └── room/                房间、日记、相册
```

**想彻底重置**：删掉这两个目录即可，重新「开始」会全部重建。

## 隐私

- 所有数据**只存在本机**，没有任何遥测、上报、云端同步
- 群消息只在你配置的世界目录里留档
- 记忆、日记、相册都可以在世界控制台里查看和删除
- 主人 QQ 号只用于判断「谁是你」，不会外发

---

## 已知边界

- **NapCat 掉线就收不到消息**，需要自己保活
- **截图/视觉受分辨率限制**：默认截图长边会被压到 1920，精确点击小目标要配合局部放大
- **语音依赖本地 GPT-SoVITS**，没起服务就退回纯文字
- **世界控制台的人设在同步时以私聊绑定为准**，多个会话绑不同卡片时，家会话用私聊那张
- **上下文越大越慢**：概览页能看到每块的 token 占用，慢的时候先看那里
