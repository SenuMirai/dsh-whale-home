# dsh-whale-home · 鲸鱼的家

> 给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的一体化 AI 伴侣：
> **一个住在 QQ 群里的群友** + **一个让她过日子的世界控制台**。
> 两个包配套部署，共用同一份人设、同一套记忆。

不是客服，不是助手，不是百科全书。她是一个会吐槽、会潜水、会突然冒怪话、
会自己写日记、会在半夜想起你的人。

---

## 这是什么

| | 说明 |
|---|---|
| **是什么** | 两个 DSH 插件：QQ 群聊伴侣 + 世界控制台 |
| **给谁用** | 想让 AI 有「人格 + 记忆 + 自己的日子」的人 |
| **要什么** | DeepSeek Harness、一个 QQ 号、NapCat |
| **不同点** | 人设卡一处编辑、处处生效；群聊与私聊记忆合并；她会自己过日子 |

---

## 它和普通「AI 机器人」哪里不一样

大多数 QQ 机器人是「来消息 → 调模型 → 回消息」。这个不是。

**1. 她会判断该不该开口**
每条消息先过一遍价值评分：谁说的、说了什么、跟她有没有关系、现在是不是接话时机。
分数不够就安静待着，不刷存在感。被 @ 到、被叫名字、被引用时才一定回。

**2. 她有一个「家」，不是一段上下文**
她住在 `~/.dsh/worlds/<世界ID>/` 里，有房间、日记本、相册、记忆痕迹。
群里聊完，日记里会多一笔；半夜睡不着，她会自己定个闹钟想事情。

**3. 人设只有一份**
角色卡写在 QQ 插件里，世界控制台读同一份。改一次，群聊、私聊、家里全部跟着变，
不会再出现「群里是一个人、私下是另一个人」的割裂。

**4. 记忆分层，但都是同一份**
- **短期衔接**：最近 N 轮对话（可调，默认 60）
- **记忆痕迹**：重要的、会想起的事，按重要性和时间衰减
- **日记**：她自己写的，一天一篇
- **群近况**：群里发生的事，实时写进文件，她要用时自己去读

群聊记忆和私聊记忆**不再分家**——同一件事在群里说的和私下说的，她记得的是同一个你。

## 三种运行方式

她有三条互不干扰的路，各自读什么、写什么都不一样：

| | 普通群聊 | 世界私聊（家会话） | `/电脑` 执行通道 |
|---|---|---|---|
| **触发** | 群里有人说话 | 私聊她（`privateBackend=world`） | 私聊发 `/电脑 <任务>` |
| **人设** | QQ 插件当前卡 | 同一张卡（私聊绑定优先） | **不用人设** |
| **记忆读** | 记忆 v3 召回 + 痕迹 + 永久记忆 + 最近几轮 + 共用上下文 | dsh-world 会话最近 60 轮 + 世界提示词里的痕迹块 | 不读 |
| **记忆写** | 群聊记忆、画像、心情、日记 | 家会话、日记、痕迹 | **不写** |
| **模型** | 插件模型 | 世界模型 | 插件模型 |
| **能不能被安全防护拦** | 能 | 能 | **不走那道闸** |

> 私聊走哪条路由 `privateBackend` 决定：`world` 交给家会话，`plugin`/`chat` 走插件自己的管线。
> 目前是在设置里改，**还不能在 QQ 私聊里临时切换**——那是下一步要做的。

## 主要功能

### 一、她在群里怎么活着

| 能力 | 说明 |
|---|---|
| **价值评分接话** | 每条消息按关键词、成员身份、上下文、熟识度、好感度、夜间时段算 0~100 分，分数 + 概率双阈值决定接不接；@ / 叫名字 / 引用她是「明确在跟她说话」，直接回 |
| **冷场逻辑** | 有人说话就重置主动开口倒计时；群里热闹时她不插话，冷场时才起话题 |
| **主动搭话** | 按群/私聊单独开关：冷场阈值、概率、近远时机、冷却、每日上限、安静时段、试运行；可单独设主动语音概率 |
| **主动 @ 主人** | 接话或主动开口时按概率 @ 你，吐槽、分享群里趣事、告状。**@ 固定放在最后一条末尾**，不会出现「@你后面接的是对群友说的话」这种歧义 |
| **直接对话队列** | 她正在生成时收到的 @ / 引用会排队，不丢；主动开口给 @ 让位 |
| **多气泡** | 一句话一条，像真人打字；条数、间隔、合并短句都可调，间隔带随机抖动 |
| **嘴臭模式** | 只在被直接怼时开启，只对那个人，一句还一句；对方收手她立刻收，不翻旧账 |
| **红包识别** | 识别红包卡片说句感谢（NapCat 没有领取接口，只能识别，抢不到不怪她） |
| **群聊开关** | 逐群开关；关掉的群完全不接消息、不主动开口、不写互动 |

### 二、记忆力

| 层 | 说明 |
|---|---|
| **短期衔接** | 最近 N 轮对话，默认 60 轮，可调。**这个数字不是记忆总量**，只是「刚才聊到哪」 |
| **记忆 v3** | 带时间衰减和相关性的召回：不是把历史全塞进去，而是按当前这句话去找相关的几条 |
| **记忆痕迹** | 重要的对话被提炼成「痕迹」，相似度过高自动合并；分层衰减：核心 10 年 / 重要 30 天 / 普通 7 天半衰期 |
| **永久记忆** | 双层：全局主人记忆 + 各会话独立记忆；全局私密不进群；可手动增删、多选合并 |
| **日记** | 每条回复记录上下文、评分理由、内心吐槽；支持筛选、导出、删除单条 / 按人删 |
| **群友画像** | 每群每人独立熟识度 / 好感度；主人数值全局统一，不被互动或衰减改动 |
| **心情** | 每群独立心情，随互动升降、随时间回落；被恶意攻击会掉 |

### 三、她会过日子

| 能力 | 说明 |
|---|---|
| **自己的家** | 独立的世界目录：房间、日记本、相册、作息、闹钟 |
| **自己决定做什么** | 用 `plan_next` 说好要做什么、做到几点；闹钟响了由她自己决定接着做还是换 |
| **主动找你** | 想分享、无聊、想起你，会主动发消息过来，而不是等你开口 |
| **写日记** | 一天一篇，她自己的口吻；写不写、写多少由她定 |
| **自己写游戏** | 会趁没人注意写小游戏玩（猜成语之类），被查岗抓包就嘴硬「我在测试环境」 |
| **自己玩游戏** | 能真的打开游戏玩——靠看屏幕 + 点鼠标。**这套玩法很贵**（每一步都要把整张画面过一遍模型），所以更适合有接口的游戏：直接拿状态数据，不用猜画面 |
| **发 QQ 空间** | 手动 / 草稿 / 自动三档；配图 0~9 张（固定 / 区间 / 模型决定，可用表情包仓库）；文本 @ 名单或按概率；本地记录可筛选排序 |
| **看 B 站** | 可选的独立模块，读视频文字稿、写观后感、在评论区回人（回复前先给你审） |

### 四、她能操控电脑

| 能力 | 说明 |
|---|---|
| **屏幕与窗口** | 看屏幕、列窗口、截图（长边默认压到 1920，可调） |
| **鼠标键盘** | 点击、双击、右键、拖拽、滚动、输入文字、组合键 |
| **开程序** | 启动应用、切窗口 |
| **局部放大** | 点小目标前先用 zoom 把区域按原生分辨率截出来，坐标一比一，不放大误差 |
| **两种用法** | ① 她自己需要时调用（在家会话里想做什么就做什么）② 你私聊发 `/电脑 <任务>` 让她代办 |

`/电脑` 那条是**独立的执行通道**：不走人设卡、不写记忆、不进群近况、不写日记，
用完即走。适合「帮我在屏幕上点两下」这种临时活，不会把家搞成工厂。

### 五、声音和表情

| 能力 | 说明 |
|---|---|
| **GPT-SoVITS 本地语音** | 多角色音色（自带七个可选），七种情绪参考音，按回复文字自动选；支持试听 |
| **按群概率** | 每群可单独设发语音 / 唱歌概率，被明确要求时强制发 |
| **唱歌** | 支持演唱；失败自动退回文字 |
| **表情包** | 自动收藏群友的图、AI 打标签、按语境选图；自拍并入常用库，用「尾巴 / 自拍」标签可被明确请求选中 |
| **视觉看图** | 能看懂当前消息的图、引用的图、转发记录里的图；嵌套转发最多展开两层 |

### 六、省钱和防封

| 能力 | 说明 |
|---|---|
| **上下文预算** | 概览页逐块列出每轮请求背了多少 token（角色卡 / 世界提示词 / 记忆痕迹 / 对话历史 / 工具表），并给建议 |
| **自适应上下文** | 自包含的短句少读历史，指代、追问才读全量 |
| **安全防护档位** | 无限制 / 宽松 / 标准 / 保守，一键切换，数值跟着档位走 |
| **只限群聊的闸** | 每分钟条数、连发静默、深夜降频、拦外链、拦复读 |
| **私聊全放开** | 和你说多少句、聊到几点都不拦，只留每小时兜底 |
| **连发按回复轮数算** | 一条回复拆五个气泡也只算一次，不会把正常聊天误判成刷屏 |
| **被拦不丢话** | 冷却 8 秒以内等一会儿重发；真放弃会先告诉你一声 |
| **失败分语义** | 网络问题重试；风控信号立刻停手 |

> 这套东西只管频率和时机。她说什么、是什么性格，不归这里管。

### 七、世界控制台

| 页面 | 内容 |
|---|---|
| **概览** | 她在做什么、下次回顾、健康状态、上下文预算、今日花费 |
| **人设** | 整段纯文本，和 QQ 插件共用同一份；改一次三处生效 |
| **世界提示词** | 她怎么过日子：作息、日记写法、分条规则、允许的梗 |
| **活动记录 / 日记 / 记忆** | 可查、可调、可删 |
| **群对话** | 群里最近发生了什么 |

### 八、接入与运维

| 能力 | 说明 |
|---|---|
| **OneBot 11 / NapCat** | WebSocket 连接，自动重连、启动检查、自动拉起 |
| **多人设卡** | 多张卡；可按群绑定，未绑定跟随全局；模型 provider/model、推理档位、备用模型可按群单独选 |
| **夜间免打扰** | 支持跨午夜；夜间不主动开口，普通接话按命中扣分 |
| **白名单 / 黑名单** | 成员级白名单抬分、黑名单忽略；上下限可调 |
| **评分权重** | 基础分、同一人继续说、引用别人、单条消息等权项可单独调 |

## 安装

### 前置

| 需要 | 说明 |
|---|---|
| DeepSeek Harness | 宿主环境 |
| Node.js ≥ 20 | |
| QQ 号 | 建议小号 |
| [NapCat](https://github.com/NapNeko/NapCatQQ) | 提供 OneBot 接口，默认 ws://127.0.0.1:3001 |
| GPT-SoVITS | 可选，本地语音 |

### 两个包装到哪

```
~/.dsh/profiles/<profile>/node_modules/dsh-qq-group/     ← QQ 插件
~/.dsh/profiles/<profile>/node_modules/dsh-world/        ← 世界控制台
```

本仓库里三个包都在 `packages/` 下：

```
packages/
├── dsh-qq-group/       QQ 群聊伴侣（含预构建 lib/）
├── dsh-world/          世界控制台（含预构建 lib/ 与 client/）
└── dsh-jingjing-home/  第二套独立世界（同一个底座，路径与数据全隔离）
```

**为什么有两个世界控制台？** 一个是主世界，一个是「鲸鲸小屋」。
两份代码同源，但控制台路径（`/dsh-world` vs `/dsh-jingjing`）、桥路径、
设置页 id、世界目录、人设、记忆、日记全部独立——可以给同一个 QQ 号的
「群聊」和「私聊」配置两个不同的她，互不污染。

`lib/` 是构建产物，仓库里已经带上了，装好即可运行，不需要自己编译。

### 启用

在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 里加上两个插件条目，
然后在 DSH 的设置里就能看到「QQ 群聊」「世界控制台」「鲸鲸小屋」三页。第二套世界是可选的，不用可以在配置里 `disabled: true`。

### 第一次跑

1. 打开「QQ 群聊」→ 填 NapCat 地址和 token
2. 填你自己的 QQ 号（主人）
3. 打开「世界控制台」→ 人设页写她的角色卡
4. 世界控制台点「开始」，她会建好房间、日记本，然后醒来

│   └── stickers/            表情包仓库

## 隐私

- 所有数据**只存在本机**，没有任何遥测、上报、云端同步
- 群消息只在你配置的世界目录里留档
- 记忆、日记、相册都可以在世界控制台里查看和删除
- 主人 QQ 号只用于判断「谁是你」，不会外发

---

## 已知边界

- **NapCat 掉线就收不到消息**，需要自己保活
- **截图/视觉受分辨率限制**：默认截图长边会被压到 1920，精确点击小目标要配合局部放大
- **语音依赖本地 GPT-SoVITS**，没起服务就退回纯文字
- **世界控制台的人设在同步时以私聊绑定为准**，多个会话绑不同卡片时，家会话用私聊那张
- **上下文越大越慢**：概览页能看到每块的 token 占用，慢的时候先看那里
