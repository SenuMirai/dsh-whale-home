# 桌宠 · 两个语音版本

同一个桌宠，两种语音方案。装的时候选一个，不用改代码。

---

## 版本 A · 世界 TTS（推荐给已经跑着 QQ 插件的人）

**她的声音来自世界插件那套 GPT-SoVITS，桌宠只负责播放。**

```
桌宠说话
  → 交给世界（和 QQ 私聊同一个家会话）
  → 她用自己的音色合成语音（七角色 + 情绪）
  → 音频推回桌宠
  → 桌宠播放
```

**好处**

- **音色和 QQ 群里一模一样**——同一个人，同一个声音
- 换音色只需要改 QQ 插件里的一处，桌宠自动跟着变
- 桌宠不需要装 ffmpeg、不需要配 Python、不需要下载模型

**需要什么**

- 世界控制台在跑（`dsh-world`）
- QQ 插件配好了 GPT-SoVITS 网关
- 桌宠设置里打开「回复时念出来」

**怎么配**

1. QQ 插件 → 语音设置 → 供应商选 `gpt-sovits`，填网关地址（默认 `http://127.0.0.1:50123`）
2. 桌宠 → 语音设置 → 勾上「回复时念出来」
3. 世界控制台的 `outlets` 里要有桌宠这一项（默认已配）

```yaml
# cordis.patch.yml → dsh-world → config → outlets
- name: desktop
  url: '{origin}/dsh-whale-girl/world-reply'
  kinds:
    - reply
```

## 版本 B · 自带语音（推荐给只想装桌宠的人）

**桌宠自己用 edge-tts 合成，不依赖世界，也不依赖 GPT-SoVITS。**

**好处**

- 装了就能出声，不用配任何外部服务
- 不需要显卡、不需要模型文件
- 断网时自动静音，不影响文字聊天

**需要什么**

- 能访问微软 edge-tts 服务（首次合成需要网络）
- 系统装了 ffmpeg（用来把 MP3 转成波形；唱歌链路才需要）

**怎么配**

桌宠 → 语音设置 → 供应商选 `edge` → 挑一个系统音色（如 `zh-CN-XiaoyiNeural`）。

---

## 两个版本的区别一览

| | 版本 A · 世界 TTS | 版本 B · 自带语音 |
|---|---|---|
| 谁合成 | 世界插件（GPT-SoVITS） | 桌宠自己（edge-tts） |
| 音色 | 七角色 + 情绪，和 QQ 群一致 | 系统音色，机械一些 |
| 需要外部服务 | 世界 + GPT-SoVITS 网关 | 无（只要网络） |
| 需要模型文件 | 是（约 7GB） | 否 |
| 断网 | 世界在本地，不受影响 | 静音，文字照常 |
| 适合 | 已经在用 QQ 插件的人 | 只想用桌宠的人 |

---

## 想从 B 换到 A

1. 装好 GPT-SoVITS，启动网关（默认 `127.0.0.1:50123`）
2. QQ 插件 → 语音设置 → 供应商切到 `gpt-sovits`，填网关地址，选角色
3. 桌宠 → 语音设置 → 供应商不用改（版本 A 下桌宠不参与合成）
4. 桌宠勾上「回复时念出来」

## 附：GPT-SoVITS 七音色方案（可选参考）

如果你想让她的声音更有辨识度，可以配 GPT-SoVITS 的七个角色音色。
这是版本 A 用的方案，也是本项目作者自己用的方案。

**七个角色**：三月七、银狼、藿藿、白露、虎克、青雀、克拉拉

**七种情绪**：开心 / 生气 / 吃惊 / 中立 / 难过 / 厌恶 / 恐惧

配置入口在 QQ 插件的语音设置页：
- 供应商选 `gpt-sovits`
- 网关地址填你的 GPT-SoVITS 服务地址
- 角色从下拉里选（插件会从网关拉取可用角色列表）
- 情绪可以留空（按回复文字自动选），也可以手动指定

> GPT-SoVITS 是独立开源项目，不随本仓库分发。需要自己部署。
> 仓库地址：https://github.com/RVC-Boss/GPT-SoVITS
