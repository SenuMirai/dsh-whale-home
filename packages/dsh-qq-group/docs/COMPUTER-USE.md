# 电脑执行（路线 A，实验性）

默认关闭。只有同时满足以下条件才会进入执行循环：

```text
主人 QQ 私聊
+ 设置里开启「电脑执行」
+ 消息以 /电脑 开头
```

## 当前工具

```text
screenshot   截屏（回传给模型）
click        点击坐标
type         输入文字
keypress     快捷键
scroll       滚轮
```

不包含：

```text
shell / 任意命令
文件读写
支付
下单提交
```

## 用法

```text
/电脑 看看当前屏幕
/电脑 打开浏览器搜索奶茶
/电脑 点击屏幕中间的按钮
```

空命令会返回帮助。

## 执行循环

```text
模型规划动作
→ 插件执行 Windows 驱动
→ 截屏回传
→ 模型根据结果继续
→ 最多 N 步
```

N 在运行状态页设置，默认 3，最大 8。

## 安全边界

- 群聊不会进入此模式；
- 私聊里必须是主人账号；
- 必须有 `/电脑` 前缀；
- 只允许白名单 UI 动作；
- 不提供 shell、文件、支付工具；
- 后续如果要加 exec/浏览器/支付，必须单独开关和 QQ 内审批。

## 文件

```text
resources/windows-driver.ps1    Windows 截屏/鼠标/键盘驱动
src/qq/computer.ts              工具参数校验与 PowerShell 调用
src/qq/bridge.ts                主人私聊 /电脑 的工具循环
src/index.ts                    设置与执行器注入
```
